# pump-zone-order

PIU(펌프 잇 업) PHOENIX 2 오락실 설치본의 **존별 곡 순서 데이터** + 재현 스크립트.

## 무엇이 들어있나

- `out/*.csv`, `out/*.json` — 시리즈존·난이도존·전용채널 곡 순서, 근거(직독/확인/추론
  등급), 화면 번호 대조표. 방송 영상 프레임 판독 + 오락실 직접 확인으로 만들었다.
- `scripts/*.py` — 위 데이터로 인터랙티브 HTML 화면(`out/zone_map.html`)을 만드는 스크립트.

## 어떻게 쓰나

```
python scripts/make_zone_map.py
```

→ `out/zone_map.html` 생성(더블클릭으로 브라우저에서 열면 됨). Python 3.9+ 외
별도 패키지 설치 필요 없음(표준 라이브러리만 사용).

곡 순서 데이터만 필요하면 `out/level_zone_order.csv`(난이도존)·
`out/arcade_series_zone_order.csv`(시리즈존)를 바로 열어 쓰면 된다.

## 근거 등급

각 칸마다 등급이 붙어 있다 — 화면을 실제로 본 것(직독·곁칸·눈판독)과, 확인된 두
지점 사이를 순서 규칙으로 메운 추론(구간확정·추측)을 구별한다. `zone_map.html`에서
칸을 열면 등급과 시각(있으면)이 같이 뜬다.

## 범위

**PHOENIX 2까지다. RISE는 다루지 않는다** — 이 데이터의 출처인 설치본에 RISE
콘텐츠가 없다.

## 정확도

일부 칸은 아직 추론(등급 낮음)이고, 일부 존은 완전히 확인되지 않았다. 각 칸의
등급을 보고 판단할 것 — "구간확정"류는 확정이 아니라 추정이다.

## 라이선스

스크립트(`scripts/*.py`)는 MIT 라이선스(`LICENSE`)로 자유롭게 가져다 써도 된다. 곡 순서
데이터는 게임 자체의 사실 정보(어느 화면에 어느 곡이 있는가)를 정리한 것으로, 곡 제목·작곡가
등 게임 콘텐츠 자체의 저작권은 원 저작권자(안다미로)에게 있다.
